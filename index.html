ARROW ESCAPE

Tap an arrow to make it slide out. It can only leave if the path ahead of it is clear. Rescue the animals on every 5th level!

Select level

How to play

1. Tap an arrow to slide it out, like a snake.

2. An arrow can leave only if nothing is in front of its head.

3. A wrong tap costs one life. You start with 3 lives.

4. Hint highlights one arrow you can remove. You get 3 hints per level.

5. Every 5th level has an animal locked by 3 chains. Remove all arrows to rescue it.
